# Squaddle

A product experience built to feel alive from the first frame.

## Overview
Squaddle needed to go from prototype to a polished, production product quickly —
with authentication, data, and a UI that felt considered end to end.

## Process
Rapid prototyping into a production interface — motion, state, and data working
as one.

## Engineering
React front end on Supabase, with auth, persistence, and a continuous
deployment workflow.

## Outcome
Live in production with authentication, data, and a polished UI.
